# LP Jóias

Loja virtual de joias com identidade visual premium, desenvolvida em Next.js.

## Identidade da marca
- Estilo: luxo escuro, moderno e minimalista.
- Títulos: Libre Baskerville.
- Textos e interface: Raleway.
- Preto: #111214.
- Branco pérola: #F5F5F2.
- Prata metálica: #C0C0C0.
- Verde italiano: #008C45.
- Vermelho italiano: #CD212A.
- Cinza aço: #777C82.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Antes de publicar
1. Substituir as fotografias demonstrativas pelas imagens oficiais dos produtos.
2. Configurar o número oficial de WhatsApp da loja.
3. Definir o valor fixo da entrega.
4. Conectar banco de dados e autenticação para o painel administrativo.
5. Integrar pagamentos online em uma etapa futura.

O protótipo inicial não processa pagamentos e não persiste pedidos em um servidor. O checkout atual prepara a mensagem para o WhatsApp.
